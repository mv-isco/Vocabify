# 🛋️ The One With The Vocab

A Friends-themed English vocabulary learning app.

---

## ▶️ HOW TO RUN (3 steps)

### Step 1 — Make sure Node.js is installed
Open a terminal / command prompt and run:
```
node --version
```
You should see something like `v18.x.x` or higher.
If not, download Node.js from: https://nodejs.org

---

### Step 2 — Install dependencies
Open a terminal **inside this folder** (friends-vocab-app) and run:
```
npm install
```
This will take 1–2 minutes the first time. It downloads React and everything needed.

---

### Step 3 — Start the app
```
npm start
```
Your browser will automatically open at **http://localhost:3000** 🎉

---

---

## 💡 Tips
- Every time you want to use the app, just open a terminal in this folder and run `npm start`
- Press `Ctrl+C` in the terminal to stop the app
- Your streak and mastered words are saved in your browser's localStorage
